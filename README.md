# NEON SNAKE

A juicy, neon-themed Snake arcade game for desktop and mobile.

## [▶ Play NEON SNAKE in your browser](https://bokul-islam.github.io/neon-snake/)

**Free, no installation, no account, and no download required.** Open the link, press Enter or tap to play.

### How to play

- **Move:** arrow keys, WASD, swipe on the board, or the mobile D-pad.
- **Eat:** collect pink orbs to grow and increase your score.
- **Combo:** eat quickly to build a streak and earn extra points.
- **Bonus:** collect the glowing gold orb for 50 points before it expires.
- **Pause:** press P or Escape, or tap the pause button.
- **Sound:** press M or tap the speaker button.
- **Restart:** press Enter or R after a game, or choose Play Again.

Your top five high scores are saved in this browser on this device. There is no sign-in or server required.

### Free live hosting

The game is published with [GitHub Pages](https://docs.github.com/en/pages) at **https://bokul-islam.github.io/neon-snake/**.

- **Playable site:** https://bokul-islam.github.io/neon-snake/
- **Source:** https://github.com/bokul-islam/neon-snake

The `main` branch contains the game source. The `gh-pages` branch contains only the built website, published directly by GitHub Pages. This is a static deployment: GitHub does not need to run a build or require any GitHub Actions workflow. The `.nojekyll` file prevents Jekyll processing.

Visitors need nothing but a browser. No paid services or backend are used. The production build is self-contained; Google Fonts supplies the arcade typography, with system fallbacks if fonts are unavailable.

Built with React, Vite, TypeScript, Tailwind CSS, Canvas 2D, and synthesized Web Audio.
